# JobMailDesk Core v0.4.2

这是一次历史回看与状态同步修复版本，同时将新版使用文档、许可说明和维护制度带入发布包。

## 修复

- Obsidian 中未勾选的任务不再把已经确认、但尚无具体时间的申请进展降级为“待确认”。
- 已过期任务不再进入桌面待办和 Obsidian 待办总览，历史节点仍保留在企业进展中。
- 无明确时间、仍在简历池或等待补信息的记录只进入“待确认”和企业进展，不再污染“待办”。
- Core 扫描器不再自动创建 Research 队列；旧配置残留的 `research.enabled=true` 会被忽略，不再影响私人邮箱同步。
- 重复执行历史回看时继续使用消息哈希去重，已确认、已完成和已忽略状态不会被邮件重放复活。
- “收到邮件后 24/48/72 小时内”等相对期限会换算为绝对截止；超过 7 天仍无可解析时间的旧测评、笔试和面试通知自动转入进展历史。
- 待确认页新增按近 7 天、简历筛选、测评/笔试和面试分类的筛选栏。
- 增加完全本地的企业标准化词库，修复“在线”“AI”“27届校招”等通用词被当成企业名的问题。
- 网易雷火与网易互娱按母品牌统一通览、按事业群严格分链；不使用容易误合并子公司或业务线的模糊匹配。
- 增加“邀请于 A，于 B 失效”的测评有效窗口解析，并修复流程说明和官网操作句造成的阶段、岗位误判。

## 首次同步

- 新安装第一次成功扫描会自动回看最近 30 天，补齐已有投递和流程通知。
- 完成首次回看后恢复设置中的短窗口，默认 3 天，不会每次重新处理 30 天邮件。
- 手动执行 `scan --once --days N` 时仍以指定天数为准。

## 文档与项目治理

- README 增加“5 分钟开始使用”、匿名高清界面预览、三平台下载、隐私边界和完整操作说明。
- 发布包包含标准 MIT `LICENSE.md` 与中文许可说明。
- 新增维护、版本、Pull Request、紧急修复和回滚规则。

## 升级方式

1. 下载当前系统对应的 ZIP 和同名 `.sha256`。
2. 核对 SHA-256。
3. 从托盘退出旧版 JobMailDesk。
4. Windows 覆盖 `JobMailDesk.exe`；macOS 替换 `JobMailDesk.app`。
5. 重新启动。任务、配置、系统凭据和 Obsidian 文件不会被覆盖。

## 已知边界

- 当前仍为 prerelease。
- Windows 包尚未完成代码签名，macOS 包尚未完成 Developer ID 签名和 Apple 公证。
- Research 不属于 Core 自动流程；Core 邮件、任务、日历与 Obsidian 功能不需要 Skill、模型或 API。
