# 求职公开研究工作流

## 输入

`research-queue.jsonl` 每行一个脱敏 `ResearchRequest`：

```json
{
  "company": "样例科技",
  "role": "产品经理",
  "recruiting_project": "2027校园招聘",
  "year": 2027,
  "stage": "在线笔试",
  "topics": ["招聘流程", "面经", "问题汇总", "准备建议"]
}
```

队列不得包含邮箱、手机号、通行证、认证参数、私人 URL 或邮件正文。

## 执行

Codex 自动化在 `08:15 / 13:15 / 20:15` 检查待处理项，使用 `vibe-web-research` 的 search 模式：

1. 企业官方招聘站
2. 牛客
3. X、小红书、抖音
4. GitHub、YouTube
5. B站补充

每个平台最多保留 5 个候选，打开最强来源核验。禁止浏览器写操作、私人收藏导出、媒体下载和付费题库复制。

## 输出

原始候选：

```text
D:\WrokSpace\Obsidian-Workspace\找工作\raw\job-research\
```

草稿至少区分：

- 企业官方事实
- 招聘流程与时间经验
- 面试轮次和常见考点
- 笔试题型与准备建议
- 问题汇总与来源
- 不确定项

只有用户点击或明确说“汇入题库”后，才允许调用找工作库现有工作流去重并更新正式题库。
