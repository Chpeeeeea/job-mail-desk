# 求职进展台账模板

JobMailDesk 的 `progress_source` 默认指向这类 Markdown 台账。它是可编辑输入，保存后在组件点击“同步台账”即可刷新申请卡片。

## 已投递或已进入流程

每行保持四段结构：

```markdown
- [ ] 公司｜岗位（岗位编号）｜**当前进展**｜下一步动作 <!-- jobmaildesk:application:稳定申请ID -->
```

示例：

```markdown
- [ ] OPPO｜AI 产品经理（1839）｜**AI 面试已安排**｜准备手机 AI 场景、用户洞察和能力边界 <!-- jobmaildesk:application:app-11111111111111111111 -->
- [x] 京东｜TET 综合方向｜**群面未通过**｜停止跟进，保留复盘记录 <!-- jobmaildesk:application:app-22222222222222222222 -->
```

## 字段规则

| 字段 | 用途 |
| --- | --- |
| 公司 | 使用企业标准名；网易雷火、网易互娱等事业群不要混写 |
| 岗位 | 写精确岗位名，最好带岗位编号 |
| 当前进展 | 写当前阶段或结果，例如“笔试已安排”“一面已完成”“未通过” |
| 下一步动作 | 写一个可执行动作，不要放完整邮件正文 |
| 稳定申请 ID | 首次匹配后由 JobMailDesk 写入，不要手动改动 |

## 归档

将当前进展改为 `已归档`，再点击“同步台账”。程序关闭该申请卡片，保留本地任务历史，不会删除邮箱邮件。直接删除台账行不会删除本地任务。

`求职当前进展.md` 是自动生成的申请链快照，不要直接编辑其中的受控区域。
